## Jira Epic Template

h3. Problem statement
Clearly articulate the problem this Epic is solving, if applicable. If a problem statement does not apply to this work, you can delete this section. Make sure the correct problem statement label is applied to the ticket to meet UXD requirements. 

h3. Objective
Summarize the purpose of this work: what will be delivered and why it's valuable. This should describe the expected result of completing this work and its impact. Provide links to related resources that are needed for completing this epic.

h3. Job stories
Add any job stories that help clarify the user motivation or context behind this epic. If the problem statement already covers this, delete this section.

h3. Stakeholders
List PMs, Eng, or other collaborators / stakeholders involved in this work.

h3. Definition of Done
The following are criteria that must be satisfied before the epic can be marked Closed

* Final outcome of this epic has been reviewed by stakeholders
[For design or ideation tasks, the following criteria should also be included:]
** A link to final designs is included in a comment on this epic and necessary stakeholders have been mentioned.
** Any updates made during review have been shared with all stakeholders so that stakeholders are aware of final changes.
* [For design tasks, the following criteria should also be included:]
** A technical review has been completed.
** Microcopy has been included in the final designs.
* All children tasks or stories in this epic have been closed or moved to a follow-up epic. If a follow-up epic is created, then a link to the follow-up epic has been added to this epic.
* Include any other criteria that need to be met before closing this epic.
