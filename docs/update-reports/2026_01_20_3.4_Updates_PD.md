### MCP Tab

#### Server Data Structure
- Made mcpServers list stateful (can be updated)
- All MCP servers start disconnected by default (including Github)
- Added server properties: `connected`, `hasAuth`, `totalTools`

#### Connection Flow
1. Clicking checkbox on an unconnected server triggers 2-second loading animation
2. Lock icon changes to Spinner during authentication
3. After authentication: checkbox checked, lock becomes green unlocked icon
4. Connection Success modal opens automatically

#### Authorization Persistence
- Once a server is authorized, it stays authorized even when disabled
- Re-enabling a previously authorized server is instant (no spinner or modal)

#### Connection Success Modal
- Shows server name with "-MCP-Server" suffix
- Displays tools count: "X out of Y tools are active"
- "Edit tool selection" link opens Tools Selection modal
- "Save" button closes modal
- "Disconnect" button disconnects server and closes modal

#### Tools Selection Modal
- Full table of available tools with checkboxes
- Search input for filtering tools by name
- Pagination controls
- Select all/deselect all checkbox in header
- Sortable columns (Tool name, Description)
- Save and Cancel buttons

#### Tools Column
- Changed from "# enabled" to "# tools enabled"
- Shows sum of all enabled tools from all selected MCP servers
- Displayed as outline Label, clickable to open Tools Selection modal

#### Tab Badge
- Added badge showing count of active MCP servers
- Grey label when 0 servers active
- Green label when 1+ servers active

#### Lock Icon States
- **Locked (grey):** Server not connected
- **Spinner:** Server connecting/authenticating
- **Unlocked (green):** Server connected and authorized
